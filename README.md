# Z’amours - question masquée avant ouverture

La question courante n’est plus affichée sur le panneau Z’amours tant que Nicolas n’a pas cliqué sur **Afficher la question / ouvrir les votes**.

Déroulé :
1. Question X / 12 — masquée
2. Nicolas clique Afficher la question / ouvrir les votes
3. Le texte apparaît simultanément pour les joueurs
4. Afficher les réponses
5. Validation manuelle
6. Question suivante retourne à l’état masqué

Aucun SQL supplémentaire n’est nécessaire.
