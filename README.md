# Z’amours - régie alignée sur le Quiz

La vue Nicolas utilise maintenant le même déroulé que le Quiz :
1. Question prête et masquée
2. Afficher la question / ouvrir les votes
3. Afficher les réponses
4. Validation manuelle couple par couple
5. Question suivante, de nouveau masquée

Aucun nouveau SQL n’est nécessaire.
