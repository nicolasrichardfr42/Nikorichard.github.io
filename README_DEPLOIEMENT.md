# Le Grand Jeu du Réveillon - mise en ligne

## Contenu
- `index.html` : application web complète et autonome.
- `codes_acces.txt` : codes individuels à transmettre séparément.

## Mise en ligne la plus simple
1. Décompresser l'archive.
2. Déposer `index.html` sur un hébergement statique (GitHub Pages, Cloudflare Pages, Netlify ou l'espace web de votre choix).
3. Copier l'adresse HTTPS obtenue.
4. Générer un QR code vers cette adresse avec votre outil habituel, puis le tester en 4G/5G sur un téléphone qui n'est pas connecté à votre Wi-Fi.

## Important
Cette version est statique : chaque téléphone conserve ses coches et son anecdote localement. Les résultats ne sont pas synchronisés entre les téléphones. Nicolas utilise l'Excel comme tableau officiel. Pour des votes et scores en temps réel, il faut ajouter une base partagée, par exemple Supabase ou Firebase.
